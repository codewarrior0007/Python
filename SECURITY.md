## Reporting a Vulnerability

If you find a security issue in any script in this repository (for example,
unsafe handling of credentials, unintended data exposure, or a bug that
could cause harm if run as-is), please report it privately rather than
opening a public issue.

You can reach out via a GitHub issue marked clearly as a security concern,
or through the contact info on the maintainer's GitHub profile.

## Scope

This repository contains scripts written for **learning and demonstration
purposes**, intended for use in authorized environments only (personal
systems, labs, or systems with explicit permission to test). It is not
production security tooling.
