# Contributing

Thanks for your interest in this repo! It's primarily a personal learning
project, but suggestions and improvements are welcome.

## How to contribute

1. Fork the repository
2. Create a branch for your change (`git checkout -b my-change`)
3. Make your changes
4. Test that any scripts you modify still run without errors
5. Open a pull request describing what you changed and why

## Guidelines

- Keep changes focused — one topic per pull request.
- Match the existing header/comment style used in scripts (author, date,
  purpose, disclaimer).
- Scripts in `pythonforhackers/` are for authorized/lab use only — please
  keep contributions in that spirit.

## Questions

Open an issue if you're not sure whether a change fits the project.
